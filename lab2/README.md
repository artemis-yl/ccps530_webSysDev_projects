## Objective
Write a web page that is fully HTML5 compliant with the following requirements.

## Requirements

1. The page subject is entirely yours.  For example choose a subject, such as your personal CV, or cars or supercars.  You can use Wikipedia as a source for content and pictures.  For example, https://en.wikipedia.org/wiki/Supercar provides a starting place.  Note Wikipedia uses a Creative Commons license so you can redistribute any material such as text and/or pictures.
2. The amount of text for each section is optional (a meaningful paragraph is enough).
3. Your name must appear clearly on the main page.
4. You must use a header tag like < h1 > at least once.
5. You must use a list (unordered, ordered) at least once.
6. You can use any other HTML tags which are covered or not covered during lectures (optional).
7. You must validate your web page for HTML5 compliance at the following services and take a screenshot of the validated result to include in your report:
   * https://validator.w3.org/  (for HTML)
8. Write a brief technical report that contains all the following elements:
   * The screenshot of your designed web pages and validator results 
   * What tags you used (just write a list of them, no additional explanation is necessary)
